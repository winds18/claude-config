# Compact instructions

压缩对话时必须原样保留：

- 当前任务的目标、验收标准、任务档位（S/M/L）与用户给出的约束和授权；
- 契约权威来源与检查点 SHA，各工作包的负责人、分支与归属（可用 `integrate.py status` 复核）；
- 已在集成状态上验证过的命令与结果、仍未验证的部分、已知阻塞；
- 待决定事项与下一步动作。

可以舍弃：已读文件的原文、长日志、已被后续结论取代的探索过程。
