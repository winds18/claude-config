# 工作包模板

派发 Agent 时把下列内容作为 prompt。删去不适用的行，不要留占位符。

```markdown
## 目标
<一句话：本包完成后可观察到的结果>

## 基线
- 仓库/目录：<路径>
- 起点：分支 <name>，提交 <sha>（包含共享契约检查点）
- 先执行：<依赖安装命令，如 pnpm install --frozen-lockfile>

## 归属
- 你负责（可写）：<文件/目录 glob>
- 禁止修改：<共享类型、锁文件、迁移、全局配置……；需要改时回报，不要自己改>
- 开工先声明归属（worktree 内由 hook 强制并锁定）：用 Write 工具写 worktree 根目录 `.dev-spec-owner.json`，
  内容 `{"base": "<基线SHA>", "owned": [<上面的负责 glob>], "forbidden": [<上面的禁止 glob>]}`；返回"✓ 归属已记录"即成功
- 运行资源：端口 <n>，数据库 <name>，输出目录 <path>

## 契约
- 权威来源：<文件路径#符号 或 schema 路径>
- 关键约束：<错误语义、兼容要求、示例>

## 授权
- 可以：在当前 worktree 分支本地提交
- 禁止：push、改远端、安装全局依赖、修改归属外文件

## 验收
- <命令 1>（必须通过）
- <命令 2 / 场景>
- 不得删测试、弱化断言或跳过错误来通过

## 回报格式
1. 分支名与最终提交 SHA
2. 改动文件列表与行为变化
3. 实际运行的检查命令与结果（失败原样给出）
4. 未验证面、发现的契约问题、遗留进程/临时文件
```
